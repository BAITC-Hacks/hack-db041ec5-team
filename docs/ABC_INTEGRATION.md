# Интеграция A B C в ветке Artyom

Текущие исправления A/B и проверка реальных данных сохранены коммитом a41493b.
Ветка origin/maksim на коммите 70eb6f8 объединена через merge без удаления
этих исправлений. Исходные parquet остаются локальными и не входят в Git.

Подключены Streamlit, обзор, направленный граф с поиском gid, приоритеты,
кластеры, сценарии изъятия, белые пятна, карточки узлов и офлайн-ассистент.
Опциональный OpenAI API не требуется для работы и не вызывался при проверках.

## Согласование контрактов

- UI читает вложенное data/data, включая все 4 840 транзакций; изменения этих
  файлов учитываются в ключе кэша.
- HTML pyvis сохраняет id/source/target строками, поскольку реальные gid
  превышают безопасный диапазон Number в браузере. Внутри Python используются
  точные int, в обязательных CSV — int64.
- UI принимает flow_share > 1: после удаления пересчитывается подпитка,
  поэтому такая величина допустима по контракту модели A.
- По умолчанию используются CSV в output, при их отсутствии — output/real.
  start.ps1 запускает реальные данные; -Demo явно включает вымышленный пример.
- Сохранены max_iter=1000, строгая проверка данных, ограничения frontier,
  безопасный экспорт gid и отчёты об ошибках конфига.
- requirements-lock.txt обновлён общей версией C; все 72 установленных пакета
  прошли uv pip check.

## Запуск

```powershell
.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.venv\Scripts\python.exe -X utf8 run.py --data data --out output/real --config config.yaml
.\start.ps1
```

Если политика PowerShell запрещает скрипт, вместо последней команды:

```powershell
.venv\Scripts\python.exe -m streamlit run app.py --server.address 127.0.0.1
```

В браузере: http://127.0.0.1:8501. Интернет для графа и офлайн-ассистента
после установки зависимостей не требуется. Ключи в Git не добавляются.

## Проверка

Финальный запуск `python -X utf8 -m pytest -q --durations=5`:
**97 passed, без пропусков**, 97,76 с. Полный реальный расчёт в тесте —
61,45 с. Два предупреждения относятся к ранее зафиксированным расхождениям
датасета с описанием: 377 вместо 354 и оборот с дополнительными 0,01 KZT.
Streamlit поднят на localhost; AppTest успешно загрузил реальные результаты
и нашёл реальный большой gid без исключений.

Добавлены интеграционные проверки реальных CSV/JSON в UI, загрузки транзакций,
поиска большого gid через Streamlit AppTest, карточки и сценария изъятия через
инструмент ассистента. Дополнительно проверяется HTML с соседними gid выше 2^53,
которые нельзя безопасно хранить как JavaScript Number.

Результаты предыдущих проверок части C на синтетике в VERIFICATION_CURRENT.md
сохранены как история. Проверка реального датасета A/B — real_data_review.md.
После интеграции экран больше не является отсутствующим компонентом;
заметки о его отсутствии в ранних отчётах относятся к версии до merge.
Финальная экспертная оценка ролей и репетиция демо остаются задачами команды.
