# Проверка требований

| Требование | Состояние |
|---|---|
| Папки, зависимости, gitignore, env | A/B/C объединены |
| Streamlit и направленный граф | Готово, без внешних CDN |
| Фильтры, роли, поиск gid | Готово |
| Dashboard | Показатели, граф, топ участников, динамика, журнал и экспорт |
| Карточка клиента | Метрики, роль, приоритет, причины, входящие/исходящие |
| Ассистент | Офлайн по данным, опциональный онлайн |
| Кластеры, устойчивость, белые пятна | Готово |
| Документация | RUN_WEB.md, ARCHITECTURE.md |
| Демо | Готовый интерфейс и синтетический прогон A/B |
| Установка | Проверена в новом venv на текущей Windows-машине |

Интерфейс использует результаты расчётного модуля команды. Дополнительное
обучение модели в этой версии не добавляется. Демо-данные явно обозначены.
Остаётся проверить реальные данные команды, живой API при необходимости
и установку на отдельном компьютере.
