# Демо и проверка перед выступлением

## Сначала локально

```bash
python -m pip install -r requirements.txt
python -m pytest tests_c -q
python -m streamlit run app.py
```

Включи демо и проверь: gid 900, цепочку 101 → 920, кластер 1, AI-справку,
неизвестный gid 999999 и вопрос о пяти источниках. Сравни инструмент
common_downstream с видимыми направленными связями. Демо-gid не переносить
в аналитические алгоритмы команды.

## После интеграции — чистая машина

Используй новый клон или распакованную копию общего репозитория и новое
окружение. Положи реальные .parquet в data/.

```bash
python -m venv .venv
# Активировать .venv по инструкции README.
python -m pip install -r requirements.txt
python run.py --data data --out output
python -m pytest -q
python -m streamlit run app.py
```

Запуск run.py — ответственность B. Замерь время полного пересчёта:
по кейсу он должен уложиться в пять минут. Тесты C не заменяют тесты A/B.

## Сценарий выступления, 5 минут

| Время | Действие |
| --- | --- |
| 0:00–0:30 | B объясняет задачу и приоритеты проверки |
| 0:30–1:00 | C запускает run.py; показывает результат и время |
| 1:00–2:30 | C: граф → топ-лист → выбранный gid → правило, метрики и окружение; B объясняет роль |
| 2:30–3:15 | B разбирает frontier и ограниченность наблюдений |
| 3:15–4:00 | A: кластер и эффект изъятия по рассчитанной выгрузке |
| 4:00–4:40 | C: вопрос о нескольких источниках → ответ, gid и вызванные инструменты; «Белые пятна» |
| 4:40–5:00 | B: ценность решения и масштабирование |

## Чек-лист C перед выходом

- [ ] Демо выключено; открыты реальные выгрузки команды.
- [ ] Проверены три реальных gid; найденный узел не скрывается фильтрами.
- [ ] Виден масштаб браузера 110–125%, читаются стрелки и легенда.
- [ ] Проверены дата и полнота файлов; нет сообщений об ошибках загрузки.
- [ ] API-ключ и модель проверены на одном реальном запросе.
- [ ] При выключенном Wi-Fi граф и офлайн-вопросы продолжают работать.
- [ ] Записан резервный пяти­минутный прогон экрана на реальных данных.
- [ ] Общий README содержит схему и точную команду запуска пайплайна B.

## Короткие ответы жюри

**Что отправляется в API?** Вопрос, последние шесть текстовых сообщений
и компактные результаты инструментов. Для справки — одна карточка. Сырые
файлы и весь граф не отправляются; ключ в окружении.

**Без интернета?** Граф, вкладки и шаблонный ассистент работают локально.
Ошибки API автоматически переводят ответ в офлайн, режим виден пользователю.

**Модель не выдумывает?** Мы ограничили доступные функции, проверяем аргументы,
требуем вызов инструмента и показываем результаты. Полной гарантии для
текста LLM нет; аналитик сверяет выводы с фактами, офлайн использует шаблоны.

**Найден путь — значит прошла вся сумма?** Нет. Это структурная достижимость,
а минимум оборотов рёбер не является доказанной суммой денег по цепочке.
