# Проверка объединённой версии A/B — 23.09.2026

Последующая проверка с реальными данными и starter описана в
[real_data_review.md](real_data_review.md). Ниже — результаты этапа до их получения.

Окружение: Python 3.12, зависимости из requirements-lock.txt.
Команда: `python -m pytest -q --durations=5`.
Результат после исправлений: **46 passed, 1 skipped**, 21,15 с.
Пропущен только test_real_outputs: нет parquet организаторов.

## Найдено и исправлено

- Frontier мог получить distributor или coordinator, включая secondary_role.
  Теперь на границе допустимы только consolidator и peripheral согласно плану.
- Прямой вызов ядра пропускал неверные seed-флаги, depth, дробный n_tx,
  строковые суммы и повторяющиеся имена колонок. Общая проверка целостности
  теперь отклоняет их до вычислений; validate возвращает предупреждения.
  Числовые поля должны иметь числовой dtype, depth/n_tx — целые значения >= 0.
- Чтение/разбор конфига происходили до блока обработки ошибок, а NaN в конфиге
  ломал сериализацию отчёта. Теперь ошибки конфига записываются в run_report.json
  со статусом failed (если каталог отчёта доступен для записи).
- gid типа uint64 за пределами int64 мог переполниться при экспорте. Ядро
  теперь отклоняет такие идентификаторы с объяснением ограничения схемы CSV.

## Что проверено

Атрибуция сверяется с независимым решением системы линейных уравнений на 15
случайных графах. Есть тесты цепочек, циклов, неизвестного происхождения,
несходимости, изолятов, пустого графа, дат разных единиц точности, ролей,
устойчивости приоритетов, чистоты функций, JSON/CSV-контрактов, изъятий и CLI.
Произвольная перестановка gid сохраняет роли и приоритеты на тестовой сети.

Полный run_pipeline с исходным config.yaml и всеми extras проверен на
синтетических **2 248 узлах / 3 119 рёбрах / 4 840 транзакциях**: 16,82 с.
Проверены обязательные выгрузки, топ-50, сценарии изъятия, сходимость
атрибуции и отсутствие существенного неатрибутированного остатка.

## Границы проверки

Синтетическая сеть для замера ациклическая. Этот замер не гарантирует время
работы на любой структуре графа. Для реальных parquet ещё нужны проверка
схемы, времени работы, предупреждений атрибуции и калибровка ролевых порогов.
Интерфейс/AI части C в этой версии отсутствуют и не проверялись.
Тесты подтверждают перечисленные сценарии, а не отсутствие любых ошибок.
