Это время Python-подготовки, **не время отрисовки в браузере** и не
гарантия производительности на каждом ноутбуке. В обычном режиме показан

запуск и открытие графа на ноутбуках команды.

## Границы проверки

1. Реальных данных хакатона и кода A/B нет. Корректность их ролей,
   приоритетов, атрибуции и симуляции этим пакетом не проверена.
2. Реального API-ключа и выбранной модели нет. Протокол и ошибки проверены
   тестовым клиентом; живой ответ и квоту следует проверить после настройки .env.
3. Полноценный браузерный просмотр не завершён: Chromium установлен,
   но его запуск блокируется ограничениями системных сокетов среды.
   AppTest выполняет приложение и проверяет действия в Streamlit, но
   не запускает JavaScript vis.js и не заменяет визуальную проверку.
4. Сервер Streamlit выводит успешный старт. Между изолированными сессиями
   среды localhost недоступен, поэтому HTTP-проверка с другого процесса
   не засчитана как пройденная.
5. Python 3.11 и Windows не запускались в этой среде. Прямые зависимости
   совместимы с Python 3.11; фактическую установку команда проверяет на
   своих машинах. requirements-lock.txt — полный снимок Linux/Python 3.12,
   requirements.txt — основной файл для установки команды.
6. Полный пайплайн run.py и реальная запись пяти­минутного демо возможны
   только после объединения проекта. Порядок действий — в DEMO.md.

Пакет не заявляет, что эти внешние проверки выполнены.
