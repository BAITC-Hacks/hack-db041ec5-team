| C6: схема | docs/architecture.png и раздел README |
| C7: проверка части C | tests_c/, docs/VERIFICATION.md |
| C7: полная чистая машина и запись реального демо | Сценарий готов; выполнить после получения A/B и данных, docs/DEMO.md |
