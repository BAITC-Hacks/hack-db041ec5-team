# Запуск, GPT и демонстрация на Vercel

## Открыть готовый анализ

Сайт: https://moneygraph-hackalem.vercel.app. Пароля доступа нет.
При открытии автоматически загружается рассчитанный конкурсный набор: 2248 узлов, 3119 рёбер, 4840 операций. Это сохранённый результат настоящего пайплайна, а не зашитый список «правильных» клиентов. Кнопка «Пересчитать конкурсный набор» запускает исходные Parquet заново. «Загрузить другой набор» принимает три файла по схеме README; «Открыть конкурсный набор» возвращает конкурсные данные.

Для локальной демонстрации дважды нажмите START.cmd (Streamlit) или START_WEB.cmd (веб-версия, порт 8600). Роли и выгрузки вычисляются без интернета и без платного API. Облако — дополнительный способ показа; требование ТЗ о локальной воспроизводимости сохранено.

## Ключ OpenAI

Ключ находится только в локальном `.env`, строка `OPENAI_API_KEY`. Он также настроен как закрытая Production-переменная проекта `moneygraph-hackalem` в Vercel-аккаунте `edge-e0b4` с разрешения пользователя. `.env` и `.vercel/` игнорируются Git и не входят в архив исходников. В `.env.example` настоящий ключ не вставлять.

Помощник автоматически использует настроенный OpenAI-ключ: откройте «Ассистент» или AI-справку в карточке. Переключателя режима нет. По умолчанию модель gpt-4.1-mini; её можно изменить серверной переменной MONEYGRAPH_LLM_MODEL. При ошибке API интерфейс явно сообщает об офлайн-ответе. Подписка ChatGPT не заменяет API-баланс. На сайте без пароля включать GPT могут посетители, поэтому его запросы расходуют баланс серверного API-ключа.

При замене ключа: измените .env для локального запуска; для сайта — Vercel → Project → Settings → Environment Variables → OPENAI_API_KEY → Production, затем Redeploy. Не используйте NEXT_PUBLIC_ и не вставляйте ключ в браузерный код.

## Перед push

```powershell
git check-ignore .env .vercel/project.json
git ls-files .env .streamlit/secrets.toml
git diff --cached --stat
```

Вторая команда должна вернуть пустой результат. Не используйте git add -f для секретов. Папка showcase содержит только обезличенный конкурсный набор и результат расчёта для показа. Загруженные пользователями файлы туда не копируются. Не добавляйте архив starter (1).zip без проверки. Commit и push не выполнялись.

Повторный деплой: `npx vercel deploy --prod`. Привязка GitHub не настроена: автоматическое подключение репозитория не удалось из-за доступа. Можно подключить его через Settings → Git учётной записью с правами на репозиторий.

## Проверка по ТЗ и сценарий на 5 минут

1. Открыть сайт: 2248 участников, 3119 связей, 4840 операций, топ-50 с обоснованиями.
2. Нажать «Пересчитать конкурсный набор». Для обязательного замера на ноутбуке выполнить `python run.py --data data --out output/current --config config.yaml`; проверить status=ok и elapsed_seconds<=300.
3. Найти gid 100000003115284100: coordinator, приоритет около 0.9407, вход 2160500 KZT, выход 517000 KZT. Показать правило, баллы ролей и связи.
4. Найти gid 100000000404740100: граница 4-го колена, нулевой выход не объявляется доказанным удержанием денег. Затем разобрать случайный gid жюри.
5. Переключить раскраску по кластерам; показать размер, seed, оборот и гипотезу. Скачать Роли CSV, Кластеры CSV и Топ CSV.
Дополнительно кнопка «Все результаты ZIP» скачивает все аналитические CSV, граф и параметры расчёта одним архивом.

6. В помощнике спросить «Карточка [gid]»; показать факты инструментов. Это опциональная функция, обязательные расчёты от GPT не зависят.
7. Для проверки другого набора загрузить свои три файла: граф, карточки и помощник должны использовать новый набор.

Автотесты: `START.cmd -Check`. Полный пересчёт на опубликованном Vercel завершился за **78,4 с** (видимый результат браузерной проверки). Проверка опубликованного сайта: 2248 узлов, 4840 транзакций, топ-50, три CSV HTTP 200; настоящий ответ GPT онлайн с вызовом инструмента карточки подтверждён. Предыдущая полная проверка — 112 passed; после удаления пароля и добавления стартового набора — 17 targeted tests passed. Экспертная точность ролей и максимальные баллы жюри не гарантируются.

## Воспроизведение стартового набора

После успешного нового расчёта выполните `python scripts/prepare_showcase.py --data data --out output/current`, затем повторите деплой. Скрипт упаковывает полученные CSV, граф, параметры и три исходных Parquet в showcase; ключи не читает.

Свой набор: до 3 МБ файлов суммарно, 5000 узлов и 20000 операций; запрос/ответ до 4 МБ, функция до 300 с. Временные файлы удаляются после расчёта. Результат собственного набора находится в памяти вкладки в подписанном виде до часа; подпись не шифрует данные. После перезагрузки снова открывается конкурсный набор. Для больших данных используйте локальный Streamlit.

ТЗ: три CSV фиксированной схемы, все шесть ролей, объяснимые правила, кластеры, топ не менее 20, направленный граф, поиск gid, локальный пересчёт не более пяти минут. Эти функции сохранены. Безымянные банковские выписки и произвольные PDF не поддерживаются: нужна схема трёх файлов.
