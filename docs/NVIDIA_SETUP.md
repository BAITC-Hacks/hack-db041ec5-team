# NVIDIA API и Brev

Адрес brev.nvidia.com сам по себе не является endpoint модели. Brev API key
используется для CLI/управления Brev; доступ к развёрнутой модели настраивается
отдельно. Покупка кредитов Brev не подтверждает наличие готового Chat Completions API.

Для приложения нужен сервер с `/v1/chat/completions`, точное имя модели и,
если сервер требует аутентификацию, ключ этого сервера. Модель должна поддерживать
function calling. Ключи Brev или NGC нельзя автоматически подставлять в API Catalog.

## Вариант 1 NVIDIA API Catalog

Создайте локальный `.env` из `.env.example` и заполните:

```dotenv
MONEYGRAPH_LLM_PROVIDER=nvidia
NVIDIA_API_KEY=ВАШ_КЛЮЧ_API_CATALOG
MONEYGRAPH_LLM_BASE_URL=https://integrate.api.nvidia.com/v1
MONEYGRAPH_LLM_MODEL=ТОЧНОЕ_ИМЯ_ВЫДАННОЙ_МОДЕЛИ
```

## Вариант 2 модель NIM на вашем Brev-инстансе

После запуска NIM и настройки доступа укажите адрес именно его API.
Для локального port-forward порта 8000 пример base URL:

```dotenv
MONEYGRAPH_LLM_PROVIDER=nvidia
MONEYGRAPH_LLM_BASE_URL=http://127.0.0.1:8000/v1
MONEYGRAPH_LLM_MODEL=ИМЯ_ИЗ_ОТВЕТА_СЕРВЕРА_v1_models
NVIDIA_API_KEY=КЛЮЧ_ИМЕННО_ЭТОГО_ENDPOINT
```

Если ваш локально проброшенный NIM настроен без аутентификации, SDK всё равно
требует непустое значение: можно явно установить `NVIDIA_API_KEY=not-used`.
Это допустимо только для уже настроенного endpoint без аутентификации,
не заменяет действительный ключ API Catalog или защищённого сервера.
Туннель Brev с браузерным входом не обязательно пригоден для вызовов из SDK.

Приложение не создаёт GPU-инстансы и не расходует кредиты на их развёртывание.
При отсутствии онлайн-настроек весь обязательный сценарий доступен офлайн.

## Проверка после настройки

Перезапустите Streamlit после изменения `.env`. В боковой панели должны
отображаться NVIDIA и модель, онлайн-переключатель должен стать доступен.
Сначала задайте «Карточка …» с реальным gid из топа. У ответа должен быть
режим «онлайн», а в инструментах — get_node с этим точным gid и фактическими
числами. Затем проверьте справку, вопрос о нескольких источниках и переход
в офлайн при выключенной сети. Сравните вывод с карточкой/CSV.

Ответ «офлайн» после включения онлайн означает срабатывание fallback, а не
успешную проверку NVIDIA. Подключение конкретной модели пока не подтверждено:
её endpoint, имя и рабочие учётные данные ещё не предоставлены.

В адаптере NVIDIA используются max_tokens, tool_choice=auto и схемы без strict;
аргументы инструментов по-прежнему проверяются локально. Если модель не
вызывает инструменты, её неподтверждённый ответ заменяется офлайн-ответом.
Поддержка этих возможностей зависит от выбранной модели и конфигурации NIM.
